# simplefunction

Danny (이동원)'s page: small things you can play with, mostly on phones.

- [Groove Skater](https://groove-skater.vercel.app/): a tiny skater is the needle of a spinning record. An interactive tribute to "Roller" by Bénédict Aubry, made with his permission.

Plain HTML, served by GitHub Pages. To add a project: put its preview in `projects/<name>/` and add an `<article class="project">` to `index.html`.
